# 🌋 Caldera Blanca Benchmark Deliverables (`data/output_3d/caldera_blanca/`)

## Overview

This folder contains the complete scientific deliverable package generated for the **Caldera Blanca Crater (Lanzarote, Canary Islands, Spain)** evaluated as a positive terrestrial analog for **Lunar Mare Basalts and Volcanic Pit / Impact Craters (Moon)**.

---

## Site Specifications

- **Location:** Lanzarote, Canary Islands, Spain
- **Centroid Coordinates:** `29.0380° N, 13.7190° W` (WGS84 / EPSG:4326)
- **Local Projection:** `EPSG:32628` (UTM Zone 28N)
- **Geomorphology:** 1.2 km diameter phreatomagmatic tuff ring with a flat central crater floor surrounded by the 1730-1736 Timanfaya basaltic lava sea.
- **Lunar Mission Pairing:** Marius Hills Pit Crater & Rilles / Oceanus Procellarum transition terraces.
- **Topographic Elevation:** 135 m (crater floor) to 458 m (crater rim peak).
- **Core 100-Meter Radius Coordinates:** Centered on the inner crater rim access corridor.

## Package Files

1. **`terrain_3d.html`:**
   - Interactive 3D WebGL model generated from real IGN PNOA-LiDAR elevation data.
   - Shows the steep crater rim walls (slopes up to 28°), central depression, and 100m glowing exploration ring.

2. **`thematic_comparison_atlas.png`:**
   - 6-panel scientific atlas comparing the Caldera Blanca crater rim with the Lunar Reconnaissance Orbiter (LRO) LOLA altimetry transect across Marius Hills pit crater.

3. **`comparison_metrics.json`:**
   - Quantitative evaluation scores, confirming a **62.8% - 66.8% multi-domain scientific similarity** with lunar volcanic collapse morphology.

4. **`terrain_comparison_report.md`:**
   - Comprehensive technical report detailing lithology, trafficability for quadruped robots, thermal buffering, and Artemis mission training applications.
