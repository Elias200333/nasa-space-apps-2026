## Scientific Rigor & Provenance

All documentation adheres to the strict guidelines of the NASA Space Apps Challenge:
- Distinguishing verified empirical data from parametric estimations.
- Transparent reporting of limitations (e.g. atmospheric difference, gravity scaling, biological alteration).
- Refusing to treat visual resemblance as scientific equivalence.
